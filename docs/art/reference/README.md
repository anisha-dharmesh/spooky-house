# Reference pictures (from Dharmesh, Oct 5, 2026)

Concept pictures that show how the game should look. They are pictures, not game files: the 3D models are built to match
their **shapes and colours**.

| File | What it shows | Used for |
| --- | --- | --- |
| `01-asset-pack-overview.webp` | "3D GLB asset pack": the 9 places (my little house, Granny's big house, playground, garden, swimming pool, school, sand park, hospital, palace) with their rooms and props, plus characters, vehicles, environment and small game items | **The models to build.** Shapes and colours to match |
| `02-town-map-and-buildings.webp` | Town map with all 9 buildings and what is in every room and floor, with the level each place unlocks at | Where things go in each building |
| `03-town-layout-ui.webp` | A town map with a task list, items bar and a room strip for each building (a different set of buildings: museum, science lab, clinic) | Town layout and screen style |

Not every detail matches the game data yet (for example, Granny's house floors, the little house's rooms and the unlock levels
differ from `godot/data/rooms/`). Treat the pictures as the look, and the game data as the rules, until we decide otherwise.
