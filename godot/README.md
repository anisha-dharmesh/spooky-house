# Godot project

The game: see the main [README](../README.md) and [docs/2D_VERSION.md](../docs/2D_VERSION.md).

```bash
godot --path godot                          # play
godot --headless --path godot -- --selftest # check the rules
```

Folders: `scripts/room/` (the room), `scripts/ui/` (colours, fonts, title screen), `scripts/core/` (data and saving),
`data/` (tasks, baddies, text, rooms, house layout), `assets/` (pictures, fonts, one shader).
